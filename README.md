# demo

## instalace frameworku flask

```shell
pip install Flask
```

## spuštění aplikace¨

výchozí soubor s aplikací se jmenuje `index.py`.

```shell
flask --app index run --debug
```

## vytvoření requirements.txt

abychom dokázali zpětně vytořit virtuální prostředí ve kterém jsme aplikaci vyvíjeli.

```shell
pip freeze
```
